# Technical-Writing-Portfolio: This repo contains the course materials and sample documentation efforts. <br>

**Note:** <br> 
- Both folders **DITA - Learnings** and **GitHub Practice** are duplicated. 
- Also, all sub-folders within **Essential Technical Writing Materials** is regularly updated.<br>

**Essential Technical Writing Materials** has the following sub-folders:<br>
  1. **API Documentation/Image:** Course materials and a sample documentation written in GitHub Wikipage.<br>
  2. **Books:** Books related to technical writing.<br>
  3. **DITA XML**: Course materials and sample documentations, exploring different topic types, written using Oxygen XML Author.<br>
  4. **Functional Writer:** Course materials related to functional documentation.<br>
  5. **Git and GitHub for Writers**: Course material and sample try-outs that include adding, commiting, pushing, branching, merging, and pulling from local to GitHub repos.<br>
