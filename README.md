# Technical-Writing-Portfolio: This repo contains the course materials and sample documentation efforts.

**Note:** Both the folders **DITA - Learnings** and **GitHub Practice** are duplicated folders. Also, all sub-folders within **Essential Technical Writing Materials** is regularly updated. 

**Essential Technical Writing Materials** has the following sub-folders:
  **API Documentation/Image:** Course materials and a sample documentation written in GitHub Wikipage.
  **Books:** Books related to technical writing.
  **DITA XML**: Course materials and sample documentations, exploring different topic types, written using Oxygen XML Author.
  **Functional Writer:** Course materials related to functional documentation.
  **Git and GitHub for Writers**: Course material and sample try-outs that include adding, commiting, pushing, branching, merging, and pulling from local to GitHub     repos.
